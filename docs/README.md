# CakeQueue

CakeQueue is a command-line application for home bakers who manage custom cake orders.
Record customer and cake details, check upcoming orders, follow production progress,
and refer to returning customers' order histories.

The baker can add, list, view, edit, cancel and find orders, view customer details and
history, set daily capacity warnings, and mark orders as preparing, ready or collected.
Changes to orders are saved automatically and loaded when the application restarts.

Use Java 25 to run CakeQueue. Start with the User Guide for installation and examples.
